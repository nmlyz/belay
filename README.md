Belay is a tiny program that writes one short poem to a file: a climber above, a belayer below with one hand on the rope and one on the brake, and the moment the rope goes taut — when stopping a fall turns out to be not catching, but simply not letting go. A poem about agency, the power to stop and to stay.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
